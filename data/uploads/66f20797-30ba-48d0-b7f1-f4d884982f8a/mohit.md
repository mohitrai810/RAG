A prime demonstration of his AI engineering capabilities is his production-oriented RAG (Retrieval-Augmented Generation) & Retrieval Engine built entirely from scratch without relying on abstraction-heavy RAG frameworks like LangChain or LlamaIndex. Developed using Python, PostgreSQL, PGVector, SQLAlchemy, BGE Embeddings, OpenRouter, and Docker, the platform is designed as an end-to-end custom vector search solution. The ingestion layer handles document parsing and applies recursive chunking techniques to preserve contextual semantic boundaries while generating metadata enrichment for every ingested segment. These text chunks are embedded into high-dimensional space using 768-dimensional BGE embedding models and stored natively in PostgreSQL via the PGVector extension. When executing queries, the system combines top-K vector similarity retrieval with strict similarity-threshold filtering and a secondary cross-encoder reranking stage to reorder retrieved contexts prior to passing them into the Large Language Model (LLM) prompt context. To benchmark and validate search quality scientifically, Mohit engineered an automated evaluation suite testing a 40-query technical troubleshooting benchmark. This suite measures key information retrieval metrics, including Hit@K, Precision@K, Recall@K, and Mean Reciprocal Rank (MRR), with evidence-level relevance tracking. As a practical demonstration, he applied this custom RAG architecture to a complex 5G network troubleshooting use case, where the engine correlates raw network protocol logs against 3GPP technical specifications to supply citation-backed debugging context to network engineers.

Beyond retrieval systems, Mohit designed and built DeepDub, an advanced AI-powered multilingual video dubbing pipeline that solves the technical challenges of automated video translation, speech synthesis, and audio-visual synchronization. Built using Python, WhisperX, GPT-3.5, Edge TTS, Demucs, Rubberband, FFmpeg, and Gradio, DeepDub orchestrates a multi-stage media transformation pipeline. The system begins by executing source separation via Demucs to isolate background audio, ambient sounds, and music tracks from human speech. WhisperX handles word-level timestamped speech transcription, which is then translated into target languages using GPT-3.5 while maintaining context. Synthetic voice generation is performed via Edge TTS, which Mohit restructured into a chunk-wise parallel processing architecture—cutting end-to-end inference latency by 2.5x while keeping the background music track seamlessly intact. To overcome lip-sync mismatches common in dubbed content, he integrated pitch-preserving time-stretching algorithms via Rubberband, boosting audio-video temporal synchronization accuracy by 40%. The entire application is containerized with Docker, deployed on Hugging Face Spaces using a Gradio user interface, and is capable of processing and rendering full 30-second localized videos in under 90 seconds.
